# Steel OS

A streamlined, keyboard-first Linux environment
built on Arch Linux and Hyprland.

## Guiding Principle

"If it takes three clicks, make it one keystroke."

## Design

- Minimal applications
- Keyboard-first navigation
- WezTerm as the default terminal
- Google Chrome as the default browser and firefox for my uncle LOL
- Forge-powered development
- Reproducible configurations
