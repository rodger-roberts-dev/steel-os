Keyboard shortcuts

Super is the Windows key. Every shortcut can be changed in System Settings, Shortcuts.

KeysDoes
Super+Enter or Alt+EnterOpen the terminal
Super+Shift+EnterOpen Firefox
Super+FOpen the file manager
Super+SpaceSearch for apps, files and settings
Super+1 to 4Switch desktops
Super+Shift+1 to 4Move the window to another desktop
Super+W or Alt+F4Close the window
Super+F11Full screen
Super+TShow or auto-hide the taskbar
Super+Shift+DVirtual desktops off or on
Alt+TabSwitch windows
Print, Super+Shift+SScreenshot, or a selected area
Super+Ctrl+VClipboard history
Super+LLock the screen
Alt+C, Alt+VCopy and paste in the terminal
Super+KSee and change all shortcuts
