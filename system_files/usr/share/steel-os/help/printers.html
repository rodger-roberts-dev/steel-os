Printers, scanners and network

USB printers set themselves up, network printers are found by themselves, and the common brands need no driver download.

Add a printer

  1. USB: plug the printer in and switch it on. Steel OS sets it up by itself within a few seconds.
  2. Wi-Fi or network: most printers appear by themselves. If yours doesn't, open System Settings, then Printers, click Add and pick it from the list.
  3. Print a test page.

HP, Canon, Brother and Epson printers work without downloading a driver, as do most printers made since about 2015.

Printing to a PDF file works in every app, with no printer.

Scan

Open Skanpage from the start menu, pick your scanner, then Scan.

Open a shared folder on a Windows PC

  1. Open Dolphin, the file manager (Super+Shift+F).
  2. Click Network on the left. Other computers often appear there.
  3. If the Windows PC isn't listed, type smb:// followed by its name in the address bar, for example smb://office-pc, and press Enter.
  4. Sign in with the Windows account name and password.

Share a folder with Windows PCs

  1. In Dolphin, right-click the folder, then Properties, then the Share tab.
  2. Tick Share with Microsoft Windows (SMB), and choose who can open it and whether they can change files.
  3. On the Windows PC, open File Explorer, then Network, then this computer. Sign in with your Steel OS user name and password.

A printer or scanner that still doesn't work

A few models need the maker's own driver, which Steel OS can't include: some Brother scanners over USB (Brother's brscan) and some Canon laser printers (Canon's CAPT). Download the Linux driver from the maker's website, or report the model at steel-os.org/report and we'll look into it.
