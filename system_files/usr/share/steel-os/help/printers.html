Printers, scanners and sharing

USB printers set themselves up, network printers are found by themselves, and the common brands need no driver download.

Add a printer

  1. USB: plug the printer in and switch it on. Steel OS sets it up by itself within a few seconds.
  2. Wi-Fi or network: most printers appear by themselves within a minute of being on the same Wi-Fi. If yours doesn't, see Add a printer by hand below.
  3. Print a test page.

HP, Canon, Brother and Epson printers work without downloading a driver, as do most printers made since about 2015.

Printing to a PDF file works in every app, with no printer.

Add a printer by hand

For a printer that didn't appear by itself. Switch the printer on first; for Wi-Fi, make sure it is on the same Wi-Fi as the computer (its own menu or app shows that).

  1. Open the start menu and search for Printers, or open System Settings and choose Printers in the list on the left.
  2. Click Add Printer at the top. A list of printers the computer can see appears after a few seconds.
  3. Click your printer. It is usually listed by make and model, for example Canon MG3600 series; the word driverless or IPP next to it is fine, choose that one.
  4. Click Next. If it asks for a driver, keep the one it suggests (usually IPP Everywhere or the printer's own name) and click Next again.
  5. Give it a name you'll recognise, such as Canon upstairs, and click Finish.
  6. Click your new printer, then Print Test Page. If the page comes out, you are done.

Not in the list? Add it by its address:

  1. Find the printer's address (IP) on the printer itself: in its menu under Settings, Network or Wireless LAN, or print its network settings page. It looks like 192.168.1.45.
  2. In Add Printer, choose Manual (or Enter address) and type ipp:// followed by the address and /ipp/print, for example ipp://192.168.1.45/ipp/print. Click Next and finish as above.
  3. Still nothing? Check that the printer is on the same Wi-Fi as the computer, restart both, and try again.

A printer you removed comes back

Printers that Steel OS found by itself are found again by themselves: within about two minutes of being removed while they are still on, or as soon as the USB cable is plugged back in. To stop a printer appearing, turn it off, or leave it and simply pick another printer when you print.

Use a printer that is plugged into a Windows PC

First, check whether you need this at all. Many printers that came with a USB cable are also on your Wi-Fi: the cable was only used to set them up. If the printer's Wi-Fi light is on (solid, not blinking), it is on the network by itself; skip this section and add it as in Add a printer by hand. That is the better setup: it works even when the Windows PC is off.

If the printer really is only connected to the Windows PC, share it from there. On the Windows PC:

  1. Settings, Bluetooth & devices, Printers & scanners, click the printer, then Printer properties. On the Sharing tab tick Share this printer and give it a short name with no spaces, for example MG3620. Leave Render print jobs on client computers ticked. Click OK.
  2. Settings, Network & internet, click your connection, and set Network profile to Private.
  3. Settings, Network & internet, Advanced network settings, Advanced sharing settings: under Private networks, turn on Network discovery and File and printer sharing.
  4. Settings, System, About: note the Device name, for example FAMILY-PC.

On Steel OS:

  1. Open System Settings, Printers, Add Printer.
  2. Choose Windows Printer via SAMBA (if it isn't offered, choose Manual or Enter address).
  3. Type the address as smb://, the Windows PC's name, /, the share name: for example smb://FAMILY-PC/MG3620. If Steel OS can't find the PC by name, use its address instead, for example smb://192.168.0.35/MG3620 (on Windows: Settings, Network & internet, your connection, IPv4 address).
  4. Enter the Windows sign-in: the account's email address and password if Windows uses a Microsoft account (not the PIN), or the Windows user name and password.
  5. For the driver, pick the maker and model from the list, for example Canon, then MG3600 series. Click Next, name it, Finish, then Print Test Page.

Limits of this: the Windows PC must be on and awake for anyone else to print (on Windows, Settings, System, Power, set sleep to Never when plugged in, or wake it first), and scanning can't be shared this way, only printing. If the Windows PC's address changes after a router restart and printing stops, use the name instead, or give the PC a fixed address in the router's settings.

Share a printer that is plugged into this computer

Any printer this Steel OS computer can print to (USB or network) can be shared with the other computers at home:

  1. Open the Steel OS Portal, Welcome, Share this computer's printers, and choose On. It asks for your password once. That tells the print system to share, and opens the two ports the others need (Steel Shield keeps the firewall on).
  2. Other Steel OS or Linux PCs: the printer appears in their printer list by itself within a minute. Nothing to add.
  3. Windows PCs: Settings, Bluetooth & devices, Printers & scanners, Add device; the printer usually appears after a few seconds. If it doesn't, click Add manually, Select a shared printer by name, and type http://, this computer's address, :631/printers/, the printer's name: for example http://192.168.0.40:631/printers/Canon_MG3600 (this computer's address: System Settings, Wi-Fi & Network, your connection, Details; the printer's name as shown in System Settings, Printers, with spaces as underscores). Windows picks its own driver (Microsoft IPP Class Driver).
  4. Phones and tablets: the shared printer shows up in their print menus too (AirPrint, Mopria).

The printer works for the others only while this computer is on. To stop sharing, choose Off on the same row.

Scan

Open Skanpage from the start menu, pick your scanner, then Scan.

Open a shared folder on a Windows PC

  1. Open Dolphin, the file manager (Super+Shift+F).
  2. Click Network on the left. Other computers often appear there.
  3. If the Windows PC isn't listed, type smb:// followed by its name in the address bar, for example smb://office-pc, and press Enter.
  4. Sign in with the Windows account name and password.

Share a folder with Windows PCs

  1. In Dolphin, right-click the folder, then Properties, then the Share tab.
  2. Tick Share with Microsoft Windows (SMB), and choose who can open it and whether they can change files.
  3. On the Windows PC, open File Explorer, then Network, then this computer. Sign in with your Steel OS user name and password.

A printer or scanner that still doesn't work

A few models need the maker's own driver, which Steel OS can't include: some Brother scanners over USB (Brother's brscan) and some Canon laser printers (Canon's CAPT). Download the Linux driver from the maker's website, or report the model at steel-os.org/report and we'll look into it.
