Gaming

Steam and Proton are built in. Windows game stores are one click away.

Steam

Steam is already installed. Sign in, install your games and press Play. Windows games run through Proton automatically. Check a game on ProtonDB before you buy it.

EA app, Battle.net and Ubisoft

Install Lutris from the Steel OS Portal (Steel Apps, Games and Streaming). In Lutris, search for the store, click Install, then install your games from inside it.

Epic Games and GOG

Install Heroic from the Portal, sign in, and install your games.

Cloud gaming and streaming

  • GeForce NOW is in Steel Apps.
  • Xbox Cloud Gaming is in the Portal's Media Apps tab.
  • Twitch and Chatterino (Twitch chat) are in Steel Apps. OBS Studio for streaming is already installed.

Controllers, flight sticks and wheels

Xbox and PlayStation controllers, most clones, the Logitech F310, flight sticks such as the X52, X56 and Thrustmaster HOTAS, and racing wheels work when you plug them in or pair them in Bluetooth settings.

  • Check one works: Steel OS Portal, Gaming, Test a controller or flight stick.
  • A game without controller support: Portal, Gaming, Use a controller in keyboard-and-mouse games.
  • Racing wheels: install Oversteer from Steel Apps to set rotation and force feedback.

Gaming keypads, keyboards and mice

  • Macros and remapping for any keyboard, mouse or keypad (Razer Tartarus, Nostromo N52 and others): Portal, Gaming, Macros for keyboards, mice, keypads and controllers.
  • Razer lights and keys: Portal, Gaming, Razer devices, then Install Razer support.
  • Logitech G and other gaming mice (buttons, DPI, lights): install Piper from Steel Apps. Logitech wireless devices: Portal, Gaming, Logitech wireless keyboards and mice.

Star Citizen

  1. Portal, Gaming, Star Citizen: install or update the LUG Helper.
  2. Open Star Citizen LUG Helper from the start menu and choose to install Star Citizen.
  3. After a game patch, if it crashes or stutters: Portal, Gaming, Repair Star Citizen. If that doesn't help, update the Wine runner and DXVK in the LUG Helper.

World of Warcraft and Battle.net

If Battle.net won't open or WoW won't start after a patch: Portal, Gaming, Repair Battle.net and World of Warcraft. Still stuck? Portal, Gaming, Get the newest GE-Proton, then choose it for Battle.net in Lutris.

Some online games with anti-cheat that blocks Linux won't run on any Linux. ProtonDB lists them.
