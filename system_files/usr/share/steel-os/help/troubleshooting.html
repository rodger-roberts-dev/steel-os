Something went wrong

Quick fixes first, then how to get help.

An app won't open or misbehaves

  1. Close it and open it again.
  2. Restart the computer.
  3. Remove it and install it again from the Steel OS Portal or the App Store.

A blue screen after installing

With Secure Boot on, the first start after installing shows a blue screen about a key, only once. With Secure Boot off, it doesn't appear. It asks the computer to trust the Steel OS driver key, which graphics and gaming drivers need. It is not an error.

  1. Press any key, then choose Enroll MOK.
  2. Choose Continue, then Yes.
  3. Type the password steelos and press Enter.
  4. Choose Reboot. Steel OS then starts normally.

Skipped it, or turned Secure Boot on after installing? Steel OS still works, but some drivers (NVIDIA, for example) may not load. To get the blue screen back, open the terminal (Super+Enter) and type:

sudo mokutil --import /usr/share/ublue-os/sb_pubkey.der

It asks for your password, then for a new one-time password (twice). Restart and follow the steps above, typing that one-time password.

Something broke after an update

Restart and pick the second entry in the start-up menu. You are back on the version before. See Updates and going back.

No internet

Click the network icon on the taskbar and pick your Wi-Fi. For a cable, check it is plugged in at both ends. System Settings, Wi-Fi & Networking shows more. See Wi-Fi and home network for step-by-step fixes.

A game stopped working

In the Portal, Troubleshoot has a button to stop stuck Wine and Proton games and to reset Steam.

Forgot your password

If you set up security questions, click Forgot your password? on the login screen, then click it again to confirm. The computer restarts into a reset window: answer your three questions and choose a new password. Your files and apps are untouched.

No security questions? Another administrator on this computer can set a new password in System Settings, Users. Set up your questions any time from the Steel OS Portal, Welcome tab, Security questions.

A disk-encryption password can't be reset by anyone. Keep it somewhere safe.

Change or remove your security questions

Open the Steel OS Portal, Welcome tab, Security questions. The window says when you already have questions and starts on the ones you chose. To change them, pick questions, type all three answers and click Save: the new set replaces the old one. To remove them, click Remove my security questions. Either way you are asked for your password first, so nobody else can change them on your unlocked computer.

Report a problem

Go to steel-os.org/report. Say what you did, what you expected, and what happened, with a screenshot if you can. These details help:

  • Your computer's make and graphics card.
  • The output of sudo bootc status in the terminal (Super+Enter).
Steel OS Help is built into Steel OS (start menu, Steel OS Help) and is also at steel-os.org/help. Something missing? Tell us at steel-os.org/report.
