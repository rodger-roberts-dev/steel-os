Something went wrong

Quick fixes first, then how to get help.

An app won't open or misbehaves

  1. Close it and open it again.
  2. Restart the computer.
  3. Remove it and install it again from the Steel OS Portal or the App Store.

A blue screen after installing

With Secure Boot on, the first start after installing shows a blue screen about a key, only once. With Secure Boot off, it doesn't appear. It asks the computer to trust the Steel OS driver key, which graphics and gaming drivers need. It is not an error.

  1. Press any key, then choose Enroll MOK.
  2. Choose Continue, then Yes.
  3. Type the password steelos and press Enter.
  4. Choose Reboot. Steel OS then starts normally.

Don't choose Continue boot on the blue screen: with Secure Boot on, Steel OS can't start until the key is trusted.

Skipped the blue screen? ("bad shim signature")

With Secure Boot on, the computer then stops with bad shim signature and you need to load the kernel first. Nothing is lost; trust the key this way:

  1. Start the computer from the Steel OS USB stick again (the live desktop starts as before).
  2. Open the terminal (Super+Enter) and type: sudo mokutil --import /etc/pki/akmods/certs/akmods-ublue.der
  3. Make up a one-time password and type it twice (for example steelos).
  4. Shut down, take out the USB stick, and turn the computer on. On the blue screen choose Enroll MOK, Continue, Yes, type that password, then Reboot.

Turning Secure Boot on after installing

If Steel OS was installed with Secure Boot off, trust the key before switching Secure Boot on: in Steel OS open the terminal and type sudo mokutil --import /etc/pki/akmods/certs/akmods-ublue.der, make up a one-time password, restart and follow the blue-screen steps above. Then switch Secure Boot on in the firmware (see Turn on Secure Boot).

"Your PC is using the standard graphics driver"

PCs with an NVIDIA card get NVIDIA's own driver automatically: Steel OS downloads the NVIDIA edition in the background and asks you to restart. If the PC doesn't start properly with it, it goes back to the standard edition by itself and shows this message. Everything still works; games may run slower than they could. Steel OS tries again a week later. Click Report a problem on the message (or Portal, Report a problem): the report includes what the team needs.

The "Restart to finish setting up your graphics" message keeps coming back after you restart: that is the same problem on an older version of Steel OS, which kept trying. Click Later, open the Portal, click Update now, and restart once more; the newer version stops asking and shows the message above instead.

Something broke after an update

Restart and pick the second entry in the start-up menu. You are back on the version before. See Updates and going back.

No internet

Click the network icon on the taskbar and pick your Wi-Fi. For a cable, check it is plugged in at both ends. System Settings, Wi-Fi & Networking shows more. See Wi-Fi and home network for step-by-step fixes.

A game stopped working

In the Portal, Troubleshoot has a button to stop stuck Wine and Proton games and to reset Steam.

Forgot your password

If you set up security questions, click Forgot your password? on the login screen, then click it again to confirm. The computer restarts into a reset window: answer your three questions and choose a new password. Your files and apps are untouched.

No security questions? Another administrator on this computer can set a new password in System Settings, Users. Set up your questions any time from the Steel OS Portal, Welcome tab, Security questions.

A disk-encryption password can't be reset by anyone. Keep it somewhere safe.

Change or remove your security questions

Open the Steel OS Portal, Welcome tab, Security questions. The window says when you already have questions and starts on the ones you chose. To change them, pick questions, type all three answers and click Save: the new set replaces the old one. To remove them, click Remove my security questions. Either way you are asked for your password first, so nobody else can change them on your unlocked computer.

Report a problem or idea

Open Report a Problem or Idea from the start menu, or the Steel OS Portal, Welcome tab. No account is needed.

  1. Choose Problem or Idea, give it a short title, and say what happened or what you would like.
  2. A screenshot of your screen is taken as the window opens. Click See screenshot to check it, and untick Include the screenshot if it shows anything private.
  3. The window lists the computer details it adds (Steel OS version, graphics, memory). No names and no files. Untick them if you prefer.
  4. Click Send. You get a reference number.

Reports go to the Steel OS team only; screenshots are never made public. Not on Steel OS? Use steel-os.org/report.

Steel OS Help is built into Steel OS (start menu, Steel OS Help) and is also at steel-os.org/help. Something missing? Tell us at steel-os.org/report.
